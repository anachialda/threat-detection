# threat-detection
Forschungsprojekt: Vergleich Random Forest vs. LLMs (Llama 3.1 8B, GPT-6 Luna) auf CIC-IDS2017

- `Random_forest.ipynb`: Datenbereinigung, Random Forest, LOAO, Stichprobe für LLMs
- `LLM_experiment.ipynb`: LLM-Experimente (Zero-/Few-Shot) und Vergleich
- `results/`: alle Ergebnisse als CSV

Daten: CIC-IDS2017, Wednesday-WorkingHours.csv (nicht in Repo)
